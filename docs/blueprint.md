# **App Name**: Blogify

## Core Features:

- Post Management: Allow users to create, edit, and delete blog posts.
- Post Listing: Display a list of blog posts with title, excerpt, and date.
- Post Display: Display the full content of a blog post, along with metadata.

## Style Guidelines:

- Primary color: White or light grey for a clean background.
- Secondary color: Dark grey or black for text to ensure readability.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clean and responsive layout that adapts to different screen sizes.
- Simple and consistent icons for navigation and social sharing.
- Subtle animations for transitions and hover effects to enhance user experience.
